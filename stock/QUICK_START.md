# 🚀 股票实时报价获取 - 快速开始指南

## 📋 功能概述

本工具可以获取A股所有股票的实时报价数据，包括：
- 当前价格、涨跌幅、成交量等基本信息
- 今开、昨收、最高、最低等价格信息
- 市盈率、市净率、总市值等估值指标
- 支持CSV、JSON、Excel等多种输出格式

## 🎯 快速开始

### 1. 获取前50只股票报价（推荐新手）
```bash
cd stock
python quick_quotes.py
```

### 2. 使用命令行工具（推荐）
```bash
# 获取前50只股票
python get_quotes_cli.py -c 50

# 获取指定股票代码
python get_quotes_cli.py -s 000001 000002 600000

# 获取前100只股票，输出Excel格式
python get_quotes_cli.py -c 100 -f excel

# 获取前200只股票，增加延迟避免请求过快
python get_quotes_cli.py -c 200 -d 0.2
```

### 3. 获取大量股票（高级用户）
```bash
python get_all_quotes.py
```

## 🔧 命令行参数说明

| 参数 | 简写 | 说明 | 默认值 |
|------|------|------|--------|
| `--count` | `-c` | 获取股票数量（0表示所有） | 50 |
| `--stocks` | `-s` | 指定股票代码列表 | - |
| `--format` | `-f` | 输出格式（csv/json/excel/all） | csv |
| `--delay` | `-d` | 请求间隔秒数 | 0.1 |
| `--output` | `-o` | 输出目录 | generated/em |
| `--no-save` | - | 不保存文件，只显示结果 | False |

## ⚠️ 注意事项

### 1. 请求频率
- 默认间隔：0.1秒
- 建议不要设置过短，避免被服务器限制
- 大批量获取时建议增加延迟

### 2. 网络稳定性
- 确保网络连接稳定
- 网络不稳定时建议启用重试机制

### 3. 数据准确性
- 数据来源于东方财富网
- 建议在交易时间内获取
- 非交易时间数据可能不是最新的

## 🚨 常见问题

### Q: 获取失败怎么办？
A: 检查网络连接，增加延迟时间，或使用重试机制

### Q: 如何获取所有股票？
A: 使用 `python get_quotes_cli.py -c 0`，但需要很长时间

### Q: 可以自定义输出格式吗？
A: 支持CSV、JSON、Excel格式，使用 `-f` 参数选择

### Q: 如何避免请求过快？
A: 使用 `-d` 参数增加延迟，如 `-d 0.2` 表示0.2秒间隔
