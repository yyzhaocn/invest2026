### 6. 更多热门品类（跨市场问句）

#### 港股

- 小米概念，近三天涨跌幅从大到小排序

- 近一个月成交金额最大的美股

- 网上发售数量超过 1 亿的可转债

- 昨天开盘价排名前十

- 各个品种的合约月份

#### 宏观

- 韩元中间价

## 三、常用问句与解析注意

### 人气 / 热股

| 问句 | 效果 |
|------|------|
| `同花顺热股榜` | ✅ 返回个股热度 Top 50（按热度排名） |
| `同花顺人气排行股票` | ⚠️ 易被解析为「同花顺(300033)」单股，不推荐 |
| `人气排名，人气增速环比` | 首页推荐；可按人气增速筛选 |

**热股榜解析条件（示例）**：

- 个股热度排名 ≤ 50
- 个股热度从大到小排名
- 选出 A 股

**结果字段**：股票代码、简称、现价、涨跌幅、个股热度排名、个股热度

### 其他写法示例

```
今日涨停，涨停原因，非st
kdj金叉，macd金叉的股票
底部反转且底背离
连续涨停
```

多个条件用 **分号** 隔开，例如：`非st；今日涨幅>5%；主力净流入>1亿`

## 四、导入自选股分组（本项目）

### 分组命名约定

与 `README_strategies.md` 一致，自动追加 **`_{YYYYMMDD}`**：

| 输入 | 实际分组名 |
|------|-----------|
| `底部反转底背离` | `底部反转底背离_20260626` |
| `同花顺热股榜` | `同花顺热股榜_20260626` |
| 已有 `_20260626` 后缀 | 不再重复追加 |

工具函数：`module_cache_policy.ensure_dated_pick_group_name()`、`iwencai_pick_group_name()`

### Web 批量导入

1. 打开应用 **动态选股** 页（`favorites`）
2. 左侧 **批量导入**，粘贴问财结果表格或代码列表
3. 选择已有分组，或在「新建分组」填写名称（**无需手写日期**，服务端自动追加）
4. 点击导入

API：`POST /api/favorites/import`

```json
{
  "text": "001399 惠科股份\n000725 京东方A",
  "group_name": "同花顺热股榜_20260626",
  "create_group": true
}
```

写入目标：`shared/favoriteStocks.ini` + `shared/stockProperties.json`

### 分组命名约定

与 `README_strategies.md` 一致，建议：

```
同花顺热股榜_{YYYYMMDD}
```

示例：`同花顺热股榜_20260626`（50 只，日期键 `2026-06-26`）

CSV 备份路径：`generated/em/{YYMMDD}/iwencai_hot_stocks_{YYYYMMDD}.csv`

### 从问财页面复制 HTML

`wencai_watcher.py` / `wencai_parser.py` 支持解析 `wencaiChoice.html`：

```javascript
// 在问财结果页 Console 执行，复制表格 HTML
(function() {
    const el = document.querySelector('.table-wrapper-content');
    if (!el) { console.error('未找到元素'); return; }
    const textarea = document.createElement('textarea');
    textarea.value = el.outerHTML;
    textarea.style.position = 'fixed';
    textarea.style.left = '-999999px';
    document.body.appendChild(textarea);
    textarea.select();
    document.execCommand('copy');
    document.body.removeChild(textarea);
    console.log('✅ 已复制到剪贴板！');
})();
```

保存为 `/tmp/wencaiChoice.html` 后运行 `wencai_parser.py` 或 `wencai_watcher.py`。

## 六、API 与限制

- 问财后端 `get-robot-data` 等接口在未登录 / 无 Cookie 时可能返回 **401 + 验证码**
- 浏览器已打开问财页面时，可直接从结果表格 DOM 提取数据（推荐）
- 程序化批量抓取需处理反爬与登录态，见 `ths_anykline.py` 请求头示例
