### 💡 使用小贴士

1. **组合使用**：多个条件可用逗号、空格隔开，如“**市盈率小于20，净利润增长大于30%，MACD金叉**”
2. **风险排雷前置**：优先叠加“**非ST、上市满90天、净利润为正**”等条件
3. **结果数量控制**：建议将筛选结果控制在10-30只，便于人工复核
4. **策略回测**：问财支持查看历史胜率，验证策略有效性
