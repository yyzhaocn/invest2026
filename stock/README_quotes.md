# 股票实时报价获取功能

本目录包含了获取所有股票实时报价的完整解决方案。

## 功能特点

- 🚀 **实时报价**: 获取A股所有股票的实时价格、涨跌幅等数据
- 📊 **批量处理**: 支持分批获取，避免请求过于频繁
- 🔄 **错误重试**: 自动重试失败的请求
- 💾 **进度保存**: 支持中断后继续执行
- 📈 **数据统计**: 自动生成涨跌统计和排行榜
- 💾 **多格式输出**: 支持CSV、JSON、Excel格式

## 文件说明

### 1. `quick_quotes.py` - 快速获取脚本
- 获取前50只股票的报价
- 适合快速测试和少量数据获取
- 包含基本的统计信息

### 2. `get_all_quotes.py` - 完整版收集器
- 获取大量股票的报价
- 包含分批处理、错误重试、进度保存等高级功能
- 适合获取所有股票数据

### 3. `get_all_stock_quotes.py` - 基础版本
- 简单的批量获取功能
- 适合学习和理解基本流程

## 使用方法

### 快速获取（推荐新手）
```bash
cd stock
python quick_quotes.py
```

### 获取大量股票
```bash
cd stock
python get_all_quotes.py
```

### 自定义数量
```python

# 获取前100只股票

```

## 输出数据

### 数据字段
- **基本信息**: 股票代码、股票名称、当前价格、涨跌幅
- **价格信息**: 今开、昨收、最高、最低、涨停价、跌停价
- **交易信息**: 成交量、成交额、换手率、量比
- **估值指标**: 市盈率、市净率
- **市值信息**: 总市值、流通市值
- **时间信息**: 更新时间

### 输出格式
- **CSV文件**: 适合Excel打开和分析
- **JSON文件**: 适合程序处理
- **Excel文件**: 包含格式化的表格

## 注意事项

### 1. 请求频率限制
- 默认请求间隔：0.1秒
- 建议不要设置过短的间隔，避免被服务器限制
- 大批量获取时建议使用分批处理

### 2. 网络稳定性
- 网络不稳定时建议启用重试机制
- 长时间运行建议启用进度保存

### 3. 数据准确性
- 数据来源于东方财富网
- 建议在交易时间内获取数据
- 非交易时间数据可能不是最新的

## 错误处理

### 常见错误
1. **网络超时**: 自动重试
2. **股票代码无效**: 跳过并记录
3. **API限制**: 增加延迟时间
