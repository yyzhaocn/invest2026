# 选股策略汇总

本文档汇总当前项目中**写入自选股分组**的自动化选股策略：所用数据、筛选逻辑、分组命名与产出文件。

> 分组写入目标：`shared/favoriteStocks.ini` + `shared/stockProperties.json`  
> 数据根目录：`generated/em/{YYMMDD}/`

### 1. 上涨概率选股

## 四、数据文件说明

| 文件模式 | 典型字段 | 使用策略 |
|----------|----------|----------|
| `zjlx_zlb_{YYMMDDHHMM}.csv` | 价、涨跌、换手、主力净流入/占比、行业、OHLC、振幅 | 战术、短线、底部反转、S1–S4 |
| `flow_{YYMMDDHHMM}.csv` | 市值分位、流通市值 | 战术、短线、底部反转、S1–S4 |
| `stockcomment_{YYMMDDHHMM}.csv` | TOTALSCORE、RANK、ORG_PARTICIPATE、PRIME_INFLOW | 评分吸筹、上涨概率（补分） |
| `stockcommentC_{YYMMDDHHMM}.csv` | 综合得分、排名（紧凑） | 上涨概率页回退、行情补全 |
| `bk_flow_{YYMMDDHHMM}.csv` | 板块主力净流入 | 短线/战术热点板块（inline 脚本） |
| 东财 API `RPT_STOCK_CHANGERATE` | RISE_1/5_PROBABILITY | 上涨概率选股 |

**查找最新文件**：

- zjlx：`utils_reem.find_latest_zjlx_zlb_file()`
- stockcomment：`utils_reem.find_latest_stockcomment_files()`

## 七、后续改进（建议）

1. 将战术/短线/底部反转/评分吸筹迁入 `strategy_picks.py` 或独立 `legacy_picks.py`
