# Glossary

**Active management** — scaling out, trailing stops, letting winners run, per pre-planned rules (Ch 8)

**Anchoring** — being stuck on entry price when managing the trade (Ch 11)

**Climax / parabolic climax** — vertical exhaustion move; trend-termination trigger (Ch 2, 5)

**Compression** — range contraction; breakout prelude (Ch 4)

**Confirmation** — multiple independent signals (HTF context + LTF trigger) agreeing (Ch 7)

**Confirmation bias** — seeking evidence for the position you hold (Ch 7, 11)

**Edge** — repeatable statistical advantage exceeding the vig (Ch 1)

**Expectancy** — win%×avg win − loss%×avg loss − costs (Ch 1)

**Failure test** — breakout that fails and returns to range; strong fade setup (Ch 5)

**Fixed fractional** — risk a consistent fraction of equity per trade (Ch 9)

**Four trades** — trend continuation, trend termination, range trading, range breakout (Ch 2)

**Gap risk** — stop becomes market order at open, worse fill (Ch 9)

**Hindsight bias** — "it was obvious" after the fact; erodes learning (Ch 11)

**Initial stop** — invalidation point, set structurally (below swing / above swing) (Ch 8)

**Loss aversion** — cutting winners, holding losers (Ch 11)

**Market cycle** — trend → range → trend, with transitions (Ch 2)

**Measured move** — structure-derived target (range height, pattern projection) (Ch 6, 8)

**Misunderstood risk** — leverage, correlation, tail events that models miss (Ch 9)

**Portfolio considerations** — too many correlated trades = one big bet (Ch 8)

**Pullback** — counter-trend move = the entry zone in trends (Ch 3)

**Recency bias** — extrapolating the last few trades (Ch 11)

**Scale-out** — partial exits at pre-planned levels (Ch 8)

**Template / playbook** — pre-written rules per trade type (Ch 6)

**Trailing stop** — locks profit while letting winners run (Ch 8)

**Transition** — trend↔range interface; highest risk/reward zone (Ch 2, 5)

**Trend continuation** — buy pullbacks within established trend (Ch 2, 3)

**Trend termination** — fade exhaustion at trend end (Ch 2, 3)

**Vig** — unavoidable transaction costs; edge must clear it (Ch 1)

**Volatility-based target** — past ATR projected forward ≈ likely leg length (Ch 6, 8)
