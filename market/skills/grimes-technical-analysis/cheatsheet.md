# Cheatsheet — Decision Guides

## Pre-Trade Checklist (Ch6/7)
```
[ ] Phase classified: trend / range / transition?
[ ] Trade type identified: 1 continuation / 2 termination / 3 range / 4 breakout?
[ ] Entry trigger defined (price-action condition)?
[ ] Initial stop structural (below swing / above swing)?
[ ] Target from structure/volatility (measured move / k×ATR)?
[ ] Management planned (scale-out, trail)?
[ ] Sizing: risk% × equity ÷ stop distance?
[ ] Confirmation applied PRE-entry (HTF context + LTF trigger)?
→ All yes = trade. Any no = skip.
```

## Four Trades — One-Line Each
| Situation | Do |
|-----------|-----|
| Uptrend pullback | buy continuation, stop below low |
| Vertical climax | fade or stand aside (termination) |
| Range extreme | fade, exit mid-range |
| Range compression/break | breakout on confirmation, else wait |

## Position Size (Ch9)
```
$risk   = equity × 1%
shares  = $risk / stop_distance
worst-case: size so a gap-through-stop is still survivable
```

## Trade Management Ladder (Ch8)
```
Entry → initial stop (structural)
   → +1R: move stop to breakeven
   → target1 (k×ATR): scale out ½
   → remainder: trail stop
   → invalidation: exit
```

## Bias Check — after every losing/violating trade (Ch11)
```
[ ] Did I follow the pre-written plan?
[ ] Was I seeking confirmation for a position (confirmation bias)?
[ ] Am I anchored to entry price (anchoring)?
[ ] Am I treating the last few trades as predictive (recency)?
[ ] Am I cutting winners / holding losers (loss aversion)?
→ Any yes = process violation; fix process, not P&L.
```

## Tells & Smells
- **"This time is different"** at a climax → that's the termination setup.
- **Adding to a range fade at the extreme** → stop now.
- **Breakout without confirmation** → likely failure test.
- **One big correlated "diversified" book** → misunderstood risk.
- **Emotional urge to deviate from the plan** → the plan exists exactly for this moment.
