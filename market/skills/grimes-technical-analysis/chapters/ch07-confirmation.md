# Chapter 7: Tools for Confirmation

## Core Idea
Confirmation = multiple independent signals agreeing (multi-timeframe + price action); the enemy is confirmation bias — seeking evidence for the position you already hold.

## Frameworks Introduced

### Multi-Timeframe Confirmation
- Higher timeframe defines context (trend/range); lower timeframe times the entry.
- Confirmation = the lower-TF action aligns with the higher-TF context.

### Price-Action Confirmation
- Structure breaks, closes beyond levels, volume/quality of the move.

### Confirmation Bias (the danger)
- The brain seeks evidence supporting the current position and ignores counter-evidence — a structural bias, not deliberate deception.
- Counter: pre-committed rules; the confirmation checklist is applied BEFORE entry, not after.

## Key Concepts
- **Context (HTF)**: trend/range determination.
- **Trigger (LTF)**: precise entry confirmation.
- **Confirmation bias**: information-processing distortion.

## Key Takeaways
1. Use higher-TF context + lower-TF trigger, not single-TF "signals".
2. Apply the confirmation checklist pre-entry; never post-hoc.
3. Journal entries that failed confirmation to expose bias.
