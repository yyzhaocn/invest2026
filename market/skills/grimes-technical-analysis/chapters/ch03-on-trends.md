# Chapter 3: On Trends

## Core Idea
Trends persist (momentum regime): entry via pullbacks, stop below structure, target measured moves — size to survive the counter-trend noise.

## Frameworks Introduced

### Trend Structure
- Trends = persistence; pullbacks = the entry zone.
- **Trend continuation** entry: wait for a pullback to support/MA, not a chase.
- **Trend termination**: exhaustion/climax after extended moves — the top/bottom trade.

### Managing Trends
- Use volatility-based stops (not fixed %): stop below the pullback low.
- Let winners run; trail stops; scale out into strength.

## Key Concepts
- **Pullback**: counter-trend move = opportunity.
- **Climax**: vertical move = termination risk.

## Key Takeaways
1. Buy pullbacks, not breakouts-to-chase, in established trends.
2. Stop below structure; size by volatility.
3. Exhaustion (climax) is the signal to exit, not enter.
