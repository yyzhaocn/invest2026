# Chapter 10: Trade Examples

## Core Idea
Worked trades show the full loop: context → trade type → entry → stop → target → management → outcome — study the process, not the P&L.

## Frameworks Introduced

### The Example Pattern
Each example walks: market cycle phase → four-trade classification → template rules → initial stop → target → active management → exit reason.

### Lessons From Examples
- **Trend continuation**: pullback entry + structural stop → runner.
- **Failure test**: breakout failure → fade → strong mean reversion.
- **Range fade**: extreme entry, mid-range exit, stop beyond extreme.
- **Parabolic climax**: stand aside or counter-trend with tight rules.

## Key Takeaways
1. Replay examples for the *process* — decisions, not outcomes.
2. Notice where rules were violated; violations are the learning.
3. Build a library of your own examples in the same template.
