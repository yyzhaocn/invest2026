# Patterns & Techniques

## Trade Template (Ch6) — fill in BEFORE entry
```
Phase (trend/range/transition)   Trade type (1-4)
Entry trigger (precise price-action condition)
Initial stop (structural: below swing / above swing)
Target (measured move / volatility projection, e.g. k×ATR)
Management (scale-out ladder, trailing rule)
```
When to use: every trade. Trade-offs: no template = no trade.

## Four Trades Quick Rules (Ch2)
| Trade | Entry | Stop | Failure mode |
|-------|-------|------|--------------|
| Trend continuation | pullback to support/MA | below pullback low | trend ends (climax) |
| Trend termination | fade climax | beyond climax extreme | trend persists |
| Range trade | fade extreme | beyond extreme | range breaks out |
| Range breakout | confirmed transition | inside range | failure test → fade |

## Fixed Fractional Sizing (Ch9)
```
Position size = (equity × risk%) / stop_distance
risk% 0.5-1% per trade typical; size for worst-case (gap) fills
```

## Volatility-Based Target (Ch6/8)
- Leg length ≈ recent ATR × (1-2) projected from entry.
- Scale-out ladder: ½ at first target, trail rest.

## Transition Discipline (Ch5)
- Breakouts need confirmation (close beyond + structure), not a poke.
- Failed breakout → fade (failure test).
- Climax/parabolic → stand aside or tight counter-trend rules.

## Anti-Bias Protocol (Ch7/11)
- Confirmation checklist applied PRE-entry only.
- Journal every trade: why entered, emotions, rule violations.
- Review weekly for bias patterns (confirmation, loss aversion, recency).
