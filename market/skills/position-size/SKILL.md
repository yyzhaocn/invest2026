# position-size — 仓位与风控

基于日 K 波动率（ATR14）与资金/风险参数，计算建议买入仓位、止损价与风险敞口。

## 使用

```bash
python3 market/skills/position-size/scripts/position-size.py <代码> \
    [--capital 100000] [--risk-pct 2] [--atr-mult 2] \
    [--method fixed|risk|kelly] [--fixed-pct 0.2] [--win-rate 0.5] [--payoff 2] \
    [--target-price 60] [--json]
```

参数：

- `--capital`：可用资金（默认 10 万）
- `--risk-pct`：单笔风险预算 = 资金 × %（默认 2%，即单笔最多亏 2000）
- `--atr-mult`：止损距离 = 倍数 × ATR14（默认 2）
- `--method`：仓位算法
  - `fixed`：固定比例（`--fixed-pct` 默认 20% 资金）
  - `risk`（默认）：风险预算法 —— 股数 = 风险金额 / 止损距离
  - `kelly`：凯利公式 `f = 胜率 - (1-胜率)/赔率`（`--win-rate`/`--payoff`），并按风险预算封顶
- `--target-price`：目标价（用于输出盈亏比）

## 输出示例

```
寒武纪 688256 ｜ 现价 1132.99 ｜ ATR14 105.68
建议止损价: 921.63（-18.66%，2.0×ATR）
风险预算: 2,000.00（资金 2.0%）
风险法仓位: 9 股 ≈ 10,196.91（9.9% 资金）｜ 单笔风险 1,941.85
止盈目标 1500 → 盈亏比 3.10
```

## 口径

- ATR14 = 最近 14 日真实波幅均值（东财日 K 前复权）
- 股数向下取整到 100 股（科创板可 1 股，`--allow-odd` 放行）
- 凯利仓位超过风险预算时按风险预算封顶（防过度杠杆）
- 仅供模拟盘参考，不构成投资建议
