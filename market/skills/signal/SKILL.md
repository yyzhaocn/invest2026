# signal — 技术信号扫描

对一组股票计算当日技术信号，输出信号清单。

## 使用

```bash
python3 market/skills/signal/scripts/signal.py <代码...> [--block 板块] [--portfolio] \
    [--breakout-window 20] [--only 金叉,死叉,新高,新低,超买,超卖,放量] [--top N] [--json]
```

输入（三选一）：

- `<代码...>`：直接给股票代码（空格分隔）
- `--block 板块`：板块内全部股票（代码或名称，如 `半导体材料`）
- `--portfolio`：当前模拟盘持仓

信号（默认全开，`--only` 可筛选）：

| 信号 | 条件 |
|------|------|
| 金叉 | MA5 上穿 MA20（今日） |
| 死叉 | MA5 下穿 MA20（今日） |
| 新高 | 收盘 = 近 N 日最高（默认 20 日） |
| 新低 | 收盘 = 近 N 日最低 |
| 超买 | RSI14 > 70 |
| 超卖 | RSI14 < 30 |
| 放量 | 成交量 > 1.5 × 20 日均量 |

## 输出示例

```
寒武纪 688256 ｜ 收盘 1132.99 (+6.62%) ｜ 信号: 金叉, 放量
青岛啤酒 600600 ｜ 收盘 53.87 (-0.13%) ｜ 信号: (无)
```

`--json` 输出结构化信号，便于后续程序化处理（如接入 portfolio 风控）。

## 数据源

- 日 K：`_shared/kline.py`（东财 kline 前复权，klt=101）
- 板块：`_shared/boards.py resolve_block` + 板块成分
