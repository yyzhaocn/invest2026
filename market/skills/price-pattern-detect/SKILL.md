# price-pattern-detect — 价格结构形态检测

检测多日结构形态（双顶/双底、头肩顶/底），规则化（枢轴 + 容差 + 颈线 + 确认）。

## 使用

```bash
python3 market/skills/price-pattern-detect/scripts/price-pattern-detect.py <股票代码> [--tol 0.03] [--json]
```

参数：

- `--tol`：两个顶/底相似度容差（默认 3%）

## 检测规则（kaabar ch10）

| 形态 | 条件 | 确认 |
|------|------|------|
| 双底 | 两个相似低点 + 中间高点(颈线) | 收盘破颈线 |
| 双顶 | 两个相似高点 + 中间低点(颈线) | 收盘破颈线 |
| 头肩顶 | 中高左右肩 + 颈线(两谷) | 收盘破颈线 |
| 头肩底 | 中低左右肩 + 颈线(两峰) | 收盘破颈线 |

- **量度涨幅** = 形态高度（颈线到极值）投影 → 目标位

## 输出

- 终端：形态识别、各点、颈线、量度目标、确认状态、结论
- PNG：K线 + 形态点连线 + 颈线 + 目标区间 + 突破标注（`/tmp/price_<code>.png` 自动打开）
