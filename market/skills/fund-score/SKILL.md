# fund-score — 基金评分

对基金按 5 因子打分（满分 100），输出总分与分项明细。

## 使用

```bash
python3 market/skills/fund-score/scripts/fund-score.py <代码...> [--json]
```

## 评分模型（满分 100）

| 因子 | 分值 | 口径 |
|------|------|------|
| 收益 | 30 | 复合 = 1年×50% + 6月×30% + 3月×20%；线性映射：-50% → 0 分，+100% → 30 分 |
| 回撤 | 20 | 近 1 年最大回撤：0% → 20 分，-40% → 0 分（越小越好） |
| 波动 | 20 | 近 1 年年化波动率：10% → 20 分，60% → 0 分（越低越好） |
| 规模 | 15 | 适中偏好：0-100 亿线性至 15 分；100-1000 亿递减（过大折分） |
| 集中度 | 15 | 前十大重仓占比：50% 得满分，偏离越大分越低 |

各因子按锚点线性插值并截断；数据缺失的因子给中位分。分项可叠加为总分，用于同池横向比较（不同池绝对分仍可比）。

## 数据源

- 净值/规模/经理：`_shared/fund.py`（pingzhongdata）
- 持仓集中度：东方财富基金持仓接口（最新季度报告）
