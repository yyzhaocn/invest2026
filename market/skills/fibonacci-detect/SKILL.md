# fibonacci-detect — 斐波那契关键位检测

自动从最近摆动高低点拉出斐波那契回撤/投影位，可视化并给结论。

## 使用

```bash
python3 market/skills/fibonacci-detect/scripts/fibonacci-detect.py <股票代码> [--swing 20] [--json]
```

参数：

- `--swing N`：摆动点回溯窗口（默认 20 根K线找最近摆动高低点）

## 输出

- 终端：摆动区间、各级回撤位、161.8% 投影、**汇聚区**（多级接近）、当前价相对位置、23.6% 再整合提示
- PNG：K线 + 各回撤水平线（61.8% 高亮）+ 汇聚区底色 + 当前价标记（`/tmp/fibonacci_<code>.png` 自动打开）
- `--json`：结构化关键位

## 关键位

| 回撤 | 意义 |
|------|------|
| 23.6% | 浅回撤（强趋势再整合位）|
| 38.2% / 50% | 常规回撤支撑/阻力 |
| 61.8% | 黄金位（最强）|
| 78.6% | 深度回撤 |
| 161.8% | 投影目标（突破后）|

## 数据源

- 日 K：`_shared/kline.py`（东财→新浪兜底）
