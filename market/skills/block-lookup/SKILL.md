# block-lookup — 个股行业归属查询

查询任意 A 股在东财行业分类中的**一级/二级/三级**归属（含 BK 代码）、地域板块与概念标签。

## 使用

```bash
python3 /Users/yyz/.agents/skills/stock/block-lookup/scripts/block-lookup.py <股票代码或名称> [--json]
```

参数：

- `查询词`：6 位代码或股票名称（名称走东财 suggest 接口解析）
- `--json`：输出 JSON
- `--refresh`：强制刷新行业板块缓存（默认 1 小时缓存，复用 _shared/boards.py）

## 输出示例

```
云南锗业 (002428) 东财行业归属：
  一级: 有色金属 (BK0478)
  二级: 小金属 (BK1027)
  三级: 其他小金属 (BK1624)
  地域: 云南板块
  概念: 稀缺资源,光伏概念,小金属概念,半导体概念,...
```

## 实现原理

1. **个股行业字段**：`push2delay /api/qt/stock/get` 的 `f127`（东财行业名，通常为二级）、`f128`（地域板块）、`f129`（概念标签）
2. **板块分级**：`_shared/boards.py` 的 `load_boards("行业")` 合并拉取东财行业一/二/三级全列表（clist t=2，含 level 字段）
3. **匹配逻辑**：
   - 二级 = f127 精确匹配
   - 三级 = 优先 `基名+Ⅲ` / `其他+基名` / 同名；兜底 `基名` 前缀（如 半导体→半导体设备/材料）
   - 一级 = `基名.startswith(一级名)`（电子化学品Ⅱ→电子）；无前缀关系时查 `IND_MAP` 映射表（小金属→有色金属、白酒→食品饮料、半导体→电子、专用设备→机械设备 等，见脚本内常量）

## 注意事项

- 东财行业命名不统一（`电子化学品Ⅱ` 带后缀 vs `小金属` 无后缀），三级/一级匹配可能为近似——模糊时输出仍是 BK 板块，可再用 block-list 交叉验证
- 北交所（920/8/4 开头）个股 secid 前缀按 `0.` 处理，部分板块接口可能无数据
- 数据源依赖 push2delay（东财 WAF 对弱 UA 拦截，脚本已用强 UA + quote.eastmoney.com Referer）
- 概念标签来自 f129（逗号分隔），含"概念"字样的为东财概念板块

## 典型用途

- 分析个股前先定位板块归属，联动 block-trend / block-list 看板块强弱
- 横向对比同一板块内个股（板块代码 → stock-hotmap 热力图 / signal 信号扫描）
