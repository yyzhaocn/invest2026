# Ch8 — Inertia

**Theme**: A 0-100 trend-momentum gauge that confirms direction.

## Core Concepts
- **Inertia** is measured on a **scale of 0 to 100**.
- **Larson convention**: **negative inertia = bullish** (sign of a long-term upward trend); **positive inertia = bearish** (illustrates distribution/down).
- **Confirmation rule**: price must be trending in the **same direction as inertia** before the signal counts.
- Set the Inertia setting on the indicator chart; watch it move across the scale.

## Signals
- **Buy confidence**: when Inertia moves from negative to positive-confidence region (**below →** bullish setup) — a change-of-character confirmation of a long-term uptrend.
- **Extremely powerful but should NOT be used alone** — combine with the other indicators (12-plus tab system).

## Style / Note
- Larson's rule for selling doesn't require Inertia (he exits on ATR/stock action instead). As an option trader, he uses ATR for exits rather than Inertia.

## Self-test anchors
- Inertia + institutional buying/volume theme.
