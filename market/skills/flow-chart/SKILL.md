# flow-chart — 个股资金流向分析

拉取东方财富日频资金流，判断主力（超大单+大单）是吸筹还是出货。

## 使用

```bash
python3 market/skills/flow-chart/scripts/flow-chart.py <代码> [--days N] [--out 路径] [--json]
```

参数：

- `<代码>`（必填）：股票代码，如 `603776`
- `--days N`：分析最近 N 个交易日（默认 20，最大 60）
- `--out, -o`：HTML 图表输出路径（默认 `/tmp/flow_chart.html`）
- `--json`：输出 JSON 数据

## 输出示例

```
永安行 (603776) ｜ 最近 20 日资金流（单位: 万）
日期        收盘    涨跌     主力净流入  主力占比  超大单    大单
2026-08-04  19.16   +0.58%    -54.3    -2.29%  -66.5   +12.1
...
5日主力合计: -321.4 ｜ 10日: +2,105.2 ｜ 20日: +4,876.3
```

## 资金流口径（东方财富）

| 类型 | 定义 |
|------|------|
| 超大单 | 单笔 ≥ 100 万 或 ≥ 20 万股 |
| 大单 | 单笔 20-100 万 或 4-20 万股 |
| **主力** | **超大单 + 大单**（最重要） |
| 中单 | 单笔 4-20 万 或 0.8-4 万股 |
| 小单 | 单笔 < 4 万 或 < 0.8 万股 |

## 解读

- 主力连续净流入 + 股价上行 → **吸筹，趋势健康**
- 股价大涨但主力净流出 → **派发/出货风险**
- 主力净占比为当日成交额中主力净额占比（%）
- HTML 图：红柱 = 主力净流入，绿柱 = 净流出，叠 5 日主力均线与收盘价线
