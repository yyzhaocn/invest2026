# block-trend — 板块近期走势

按板块代码（BKxxxx）或板块名称拉取板块指数日 K，输出近期走势：最近 N 日逐日收盘与涨跌、区间表现（5日/20日/60日/120日/250日）、走势缩略图、区间高/低点。

## 使用

```bash
python3 market/skills/block-trend/scripts/block-trend.py <板块代码或名称> [--days N] [--json]
```

参数：

- `板块`（必填）：板块代码（如 `BK0475`）或板块名称（如 `半导体`、`算力`）。可用 `block-list` 技能查到代码。
- `--days N`：最近走势表显示的天数（默认 15，最大 60）。
- `--json`：输出 JSON（含名称、区间表现、最近 N 日序列）。

## 数据源与口径

- 板块指数日 K：东方财富 `push2his.eastmoney.com/api/qt/stock/kline/get`，`secid=90.BKxxxx`（klt=101）
- 板块名解析：复用 `block-list` 的板块缓存/接口（行业+概念），名称匹配取唯一或精确命中
- 区间表现由指数收盘序列推算（22≈1月、66≈3月、132≈6月、250≈1年），日涨跌取 K 线字段

## 常见问题

- **板块名模糊**（如输入「半导体」命中多个板块）：优先精确匹配，否则取第一个，建议先 `block-list <名称>` 确认代码。
- **接口无数据**：BK 代码不存在时提示，可用 block-list 确认。
