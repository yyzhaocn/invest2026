# fund-compare — 多基金对比

对比 2 只以上基金的收益/风险/规模/经理，并分析重仓股重叠度。

## 使用

```bash
python3 market/skills/fund-compare/scripts/fund-compare.py <代码1> <代码2> [...<代码N>] [--holdings-top 15] [--json]
```

参数：

- `<代码...>`：至少 2 个基金代码（如 `161631 018124`）
- `--holdings-top N`：持仓重叠矩阵显示每只基金的前 N 大重仓（默认 15，0 关闭）
- `--json`：输出 JSON

## 口径

- 区间收益/回撤/波动率由净值序列推算（22/66/132/250 交易日 ≈ 1月/3月/6月/1年）
- 最大回撤、年化波动率为近 1 年
- 持仓为最新季度报告（数据时点见持仓接口），重叠表显示每只基金前 N 大重仓并集中的占比
