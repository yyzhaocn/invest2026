# pattern-detect — K 线形态检测与结论

基于 kaabar-technical-analysis（ch07 模式识别）的规则化检测方法：每个形态 = 明确的 OHLC 条件，结合位置/趋势上下文给出警示结论，并自动生成可视化。

## 使用

```bash
python3 market/skills/pattern-detect/scripts/pattern-detect.py <股票代码> [--days 60] [--out 路径] [--json]
```

参数：

- `<代码>`（必填）：6 位股票代码
- `--days N`：检测与图表窗口（默认 60，图表显示近 30 日）
- `--out, -o`：PNG 输出路径（默认 `/tmp/pattern_<code>.png`，自动 `open`）
- `--json`：输出结构化 JSON（形态清单 + 结论）

## 检测的形态（规则化条件）

| 形态 | 条件 | 默认含义 |
|------|------|---------|
| Doji | 实体/振幅 < 15% | 犹豫；下跌后=看涨警示，上涨后=看跌警示 |
| 锤子线 Hammer | 下影 ≥2×实体，上影小 | 下跌后=看涨 |
| 射击之星 Shooting Star | 上影 ≥2×实体，下影小 | 上涨后=看跌 |
| 看涨吞没 | 今日阳线实体包住昨日阴线实体 | 下跌后=看涨 |
| 看跌吞没 | 今日阴线实体包住昨日阳线实体 | 上涨后=看跌 |
| 光头光脚 Marubozu | 实体≈振幅（无影线）| 强趋势延续 |

## 结论生成逻辑（kaabar 方法）

1. **上下文**：MA20 上/下方 = 多头/空头区；5 日涨跌 = 短期动能
2. **警示**：形态含义 × 位置匹配 → 看涨/看跌警示（黄）
3. **确认**：警示后次日收盘方向 = 已确认/未确认/待确认
4. **综合结论**：最近窗口内最强信号的行动建议（不追高/等待确认/减仓等）

## 产物

- 终端：检测结果表 + 确认检查 + 结论
- PNG：K线（红涨绿跌）+ MA20 + 形态标记（黄圈 Doji / 绿锤 / 红星等）+ 量能（透明度按量比）+ 叙事标注 + 结论文字
