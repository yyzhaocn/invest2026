# fund_pl — 基金当日持仓预计盈亏

按基金代码获取最新季度报告持仓，叠加当日实时涨跌幅，估算每只重仓股对基金净值的贡献，输出贡献表与合计预计盈亏。

## 使用

```bash
python3 market/skills/fund_pl/scripts/fund_pl.py <基金代码> [--date YYYY-MM-DD] [--top N] [--json]
```

参数：

- `基金代码`（必填）：如 `161631`、`018124`。可用 `fund_list` 技能查到。
- `--date`：报告日期，默认最新季度末（按当前日期自动推算，如 2026-08 → `2026-06-30`）。基金季报为季度末快照，非最新日期数据可能为空。
- `--top N`：只显示贡献绝对值前 N 名，默认全部。
- `--json`：输出 JSON（便于后续处理/汇总）。

## 计算口径

- **贡献%** = 股票净值占比（`netasset_ratio`） × 当日涨跌幅（`daily_change_pct`） ÷ 100
- 合计 = 全部持仓贡献之和（未计现金/债券部分，故为「估算」）
- 行情取东方财富实时/延迟接口（约 15 分钟延迟），盘中调用为实时快照

## 输出示例

```

股票代码  股票名称    净值占比%  今日涨跌%  贡献%
688256   寒武纪      10.03     +6.74    +0.676
300308   中际旭创     8.62     -5.43    -0.468
...
预计盈亏(合计): +1.4161%   (15 只持仓, 15/15 取到行情)
```

## 依赖与数据流

- 复用 `fund/fund_analyzer.py`（`FundAnalyzer.stockHolding`，东方财富 `RPT_MAINDATA_MAIN_POSITIONDETAILS` 接口），结果写入 `generated/em/fundHoldings.csv` 缓存（7 天内复用）。
- 复用 `fund/anyFund.py` 的 `fetch_daily_change_pct`（批量行情，按 80 只分批）。
- 运行目录任意，脚本通过仓库根目录相对路径自动定位 `fund/`。

## 常见问题

- **报告期数据为空**：季报披露有滞后，个别基金可能尚未披露最新季度持仓，可尝试 `--date` 传更早季度。
- **部分股票无行情**（停牌/未上市）：贡献按 0 计，输出中会标注取到行情的比例。
- **结果与基金净值不同**：估算仅覆盖股票持仓，未含债券/现金/费用，且持仓为季报快照，与实时净值有偏差属正常。
