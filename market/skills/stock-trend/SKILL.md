# stock-trend — 股票近期走势

按股票代码拉取日 K 线（前复权），输出近期走势：最近 N 日逐日收盘与涨跌、区间表现（5日/20日/60日/120日/250日 ≈ 1周/1月/3月/6月/1年）、走势缩略图、区间高/低点。

## 使用

```bash
python3 market/skills/stock-trend/scripts/stock-trend.py <股票代码> [--days N] [--json]
```

参数：

- `股票代码`（必填）：如 `688256`、`601318`。可用 `stock-list` 技能查到。
- `--days N`：最近走势表显示的天数（默认 15，最大 60）。
- `--json`：输出 JSON（含名称、区间表现、最近 N 日序列）。

## 数据源与口径

- 主源：东方财富 `push2his.eastmoney.com/api/qt/stock/kline/get`（`klt=101` 日 K，`fqt=1` 前复权），接口返回股票名称
- 兜底：新浪 `CN_MarketData.getKLineData`
- 区间表现由收盘价序列推算（交易日数近似：22≈1月、66≈3月、132≈6月、250≈1年），日涨跌取 K 线涨跌幅字段
- 走势缩略图：每字符一个交易日，`▁▂▃▄▅▆▇█` 表示窗口内相对高低

## 常见问题

- **接口无数据**：代码不存在（可用 stock-list 确认）、停牌退市或北交所个股（支持度有限）。
- **除权影响**：前复权口径，区间涨幅已还原分红送转。
