# 基金趋势分析系统 - 完整版

这是一个完整的基金趋势分析系统，可以从东方财富网站获取基金信息、趋势数据、股票持仓信息，并生成包含交互式图表的综合HTML报告。

## 🚀 系统功能

### 1. 基金基本信息分析
- 基金名称、代码、费率等基本信息
- 各期收益率（近一年、6月、3月、1月）
- 基金经理信息和评分
- 业绩评价和能力分析

### 2. 趋势数据分析
- **净值走势图** - 显示基金单位净值和收益率变化
- **股票仓位图** - 显示基金股票仓位变化趋势
- **规模变动图** - 显示基金规模历史变化
- **资产配置图** - 显示股票、债券、现金占比变化

### 3. 股票持仓分析
- 持仓股票基本信息
- 实时涨跌幅数据
- 股票表现统计和分布

## 📊 生成的图表

### 1. 净值走势图
- 双Y轴设计：左轴显示单位净值，右轴显示收益率
- 时间序列：最近30个数据点
- 交互式：支持缩放、悬停查看详情

### 2. 股票仓位图
- 折线图：显示股票仓位比例变化
- 填充区域：直观显示仓位水平
- 时间范围：最近30个数据点

### 3. 规模变动图
- 柱状图：显示基金规模历史变化
- 环比数据：显示较上期变化百分比
- 时间节点：季度数据

### 4. 资产配置图
- 堆叠柱状图：显示股票、债券、现金占比
- 多系列：不同资产类型用不同颜色
- 时间序列：季度配置变化

## 🛠️ 系统组件

### 核心脚本
1. **`fund_parser.py`** - 基金数据解析器
2. **`stock_info_parser.py`** - 股票信息解析器
3. **`fund_trends_analyzer.py`** - 基金趋势分析器
4. **`comprehensive_fund_analyzer.py`** - 综合分析器（推荐）

### 辅助脚本
- **`fund_stock_analyzer.py`** - 基金和股票综合分析器
- **`example.py`** - 使用示例

## 📈 使用方法

### 1. 综合分析（推荐）
```bash
cd fund/
python comprehensive_fund_analyzer.py 006253
```

### 2. 单独分析
```bash
# 基金趋势分析
python fund_trends_analyzer.py 006253

# 基金和股票分析
python fund_stock_analyzer.py 006253

# 仅基金信息
python fund_parser.py 006253

# 仅股票信息
python stock_info_parser.py 301061 300866 688235
```

## 📁 输出文件

所有报告保存在 `../generated/funds/` 目录：

- `comprehensive_fund_analysis_<基金代码>_<时间戳>.html` - 综合分析报告（推荐）
- `fund_trends_<基金代码>_<时间戳>.html` - 趋势分析报告
- `fund_stock_analysis_<基金代码>_<时间戳>.html` - 基金股票分析报告
- `fund_<基金代码>_<时间戳>.html` - 基金信息报告
- `stock_holdings_<时间戳>.html` - 股票持仓报告

## 🔧 技术特点

### 数据获取
- **实时数据**：从东方财富API获取最新数据
- **多源整合**：整合基金、股票、趋势多个数据源
- **智能解析**：自动解析JavaScript和JSON数据

### 图表技术
- **Chart.js**：使用Chart.js库生成交互式图表
- **响应式设计**：适配不同屏幕尺寸
- **多图表类型**：折线图、柱状图、堆叠图等

### 报告生成
- **HTML5**：现代化HTML结构
- **CSS3**：美观的样式设计
- **JavaScript**：交互式图表功能
