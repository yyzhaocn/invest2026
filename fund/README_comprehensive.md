# 基金和股票持仓综合分析系统

这是一个完整的基金和股票持仓分析系统，可以从东方财富网站获取基金信息及其持仓股票的基本信息，并生成美观的HTML报告。

## 系统组件

### 1. 基金数据解析器 (`fund_parser.py`)
- 从东方财富基金页面获取基金基本信息
- 解析基金业绩数据、持仓信息、基金经理信息等
- 生成基金信息HTML报告

### 2. 股票信息解析器 (`stock_info_parser.py`)
- 从东方财富股票API获取股票基本信息
- 获取股票代码、名称、涨跌幅等实时数据
- 生成股票持仓信息HTML报告

### 3. 综合分析器 (`fund_stock_analyzer.py`)
- 结合基金信息和股票持仓信息
- 生成综合的基金持仓分析报告
- 提供持仓股票表现概览和详细分析

## 功能特点

✅ **实时数据获取** - 从东方财富API获取最新数据  
✅ **智能数据解析** - 自动解析JavaScript和JSON数据  
✅ **美观HTML报告** - 生成专业的分析报告  
✅ **综合分析** - 结合基金和股票信息进行深度分析  
✅ **灵活使用** - 支持单独使用或组合使用  
✅ **错误处理** - 完善的异常处理机制  

## 使用方法

### 1. 单独获取基金信息
```bash
cd fund/
python fund_parser.py 006253
```

### 2. 单独获取股票信息
```bash
cd fund/
python stock_info_parser.py 301061 300866 688235 301004 600519
```

### 3. 综合分析（推荐）
```bash
cd fund/
python fund_stock_analyzer.py 006253
```

## 输出文件

所有报告都保存在 `../generated/funds/` 目录中：

- `fund_<基金代码>_<时间戳>.html` - 基金信息报告
- `stock_holdings_<时间戳>.html` - 股票持仓信息报告  
- `fund_stock_analysis_<基金代码>_<时间戳>.html` - 综合分析报告

## 报告内容

### 基金信息报告
- 基金基本信息（名称、代码、费率等）
- 业绩表现（各期收益率）
- 基金持仓（股票代码）
- 基金经理信息
- 业绩评价和资产配置

### 股票持仓信息报告
- 持仓股票基本信息
- 实时涨跌幅数据
- 股票表现统计
- 涨跌分布情况

### 综合分析报告
- 基金基本信息和业绩表现
- 持仓股票表现概览
- 持仓股票详细信息
- 综合统计分析

## 技术实现

### API接口
- **基金数据**: `https://fund.eastmoney.com/pingzhongdata/{fund_code}.js`
- **股票数据**: `https://push2delay.eastmoney.com/api/qt/ulist.np/get`

### 数据解析
- 使用正则表达式解析JavaScript变量
- JSONP回调函数解析
- 智能股票代码格式转换

### 报告生成
- 响应式HTML设计
- 现代化CSS样式
- 数据可视化展示

## 注意事项

1. 需要网络连接以获取实时数据
2. 某些基金数据可能解析失败，会显示相应提示
