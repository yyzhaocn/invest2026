# 东方财富基金数据解析器

这个工具可以从东方财富基金数据页面获取基金信息并生成美观的HTML报告。

## 功能特点

- 自动获取基金基本信息（名称、代码、费率等）
- 解析基金业绩数据（各期收益率）
- 提取基金持仓信息（股票代码）
- 获取基金经理信息
- 生成美观的HTML报告
- 支持自定义输出目录

## 使用方法

### 基本用法

```bash
cd fund/
python fund_parser.py <基金代码>
```

### 示例

```bash
# 解析基金006253（永赢消费主题C）
python fund_parser.py 006253

# 指定输出目录
python fund_parser.py 006253 --output /path/to/output/
```

### 参数说明

- `fund_code`: 基金代码（必需）
- `--output, -o`: 输出目录（可选，默认为 `../generated/funds/`）

## 输出文件

生成的HTML文件会保存在指定目录中，文件名格式为：
`fund_<基金代码>_<时间戳>.html`

例如：`fund_006253_20250922_170404.html`

## 报告内容

生成的HTML报告包含以下信息：

1. **基本信息** - 基金名称、代码、费率等
2. **业绩表现** - 近一年、6月、3月、1月收益率
3. **基金持仓** - 主要股票持仓代码
4. **基金经理** - 基金经理信息和评分
5. **业绩评价** - 各项能力评分
6. **资产配置** - 股票、债券、现金占比
7. **规模变动** - 历史规模变化
8. **持有人结构** - 机构和个人持有比例

## 依赖库

- requests
- json
- re
- datetime
- pathlib
- argparse

## 注意事项

- 需要网络连接以获取基金数据
- 某些基金数据可能解析失败，会显示相应提示
- 生成的HTML文件可以在浏览器中直接打开查看
